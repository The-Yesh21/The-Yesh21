## `08 // ENGINEERING PHILOSOPHY`

> A model is not a product. A UI is not a product. An API is not a product. A clever algorithm is not a product.
>
> **A product is the whole loop:** `input → decision → action → feedback → improvement`
>
> I don't want to know everything. I want to become the engineer who can enter an unfamiliar system, trace the moving parts, understand why it behaves the way it does, change it without breaking everything, and leave it better than I found it.
